# Sistem Manajemen Apotek

Aplikasi ini adalah **sistem manajemen apotek** yang **bebas digunakan**.  
Dibuat menggunakan **PHP, MySQL, dan template Bootstrap Stisla** untuk memudahkan pengelolaan:  
- Data obat  
- Data supplier  
- Transaksi penjualan  
- Laporan keuangan apotek

## Fitur Utama

### Input Stok Obat

- Input stok obat baru.  
- Dilengkapi dengan informasi **jatuh tempo pembayaran** untuk memudahkan monitoring hutang.  

### Input Daftar Obat

- Input dan kelola **master obat**, termasuk nama, kode, satuan, dan harga.  

### Transaksi Penjualan
- Transaksi penjualan obat secara cepat dan akurat.  
- Otomatis update stok obat.  

---

## Cara Menjalankan Aplikasi
1. Pastikan **XAMPP** atau server lokal sudah berjalan.  
2. Letakkan folder proyek di `htdocs` (misal: `/Applications/XAMPP/htdocs/apotek`).  
3. Import database `apotek.sql` ke MySQL.  
4. Buka browser dan akses: [http://localhost/apotek](http://localhost/apotek).
